> **Theme:** Pilot proof and public release candidate · **Baseline:** V0.4.104 · **Related:** [Roadmap](ROADMAP.md#proposed-path-to-10-team-readiness) · [Functional readiness report](analysis/2026-10-29-team-readiness.md)

Split oversized rows before implementation and renumber only unshipped rows. Update the changelog, user/API guides, mindmaps, archive compatibility and focused checks with the implementation, not in this planning change. No product version is bumped by this plan.

**CAIRN agent track (V0.9.0 to V0.9.32):** the line opens with a track of commits that make CAIRN a proper agent: it knows who it is, answers greetings and "what can you do" itself, stays in character for anything else, speaks in the first person in the user's language, and shows as evidence only what it read. From V0.9.10 it also proposes actions that wait for the person to confirm them: saving a memory card, moving, renaming and trashing files, indexing files uploaded in the chat, and saving a summary of the chat as an indexed note. V0.9.15 to V0.9.24 are interface commits of the same track, and V0.9.25 onward build CAIRN as a harness over files, evidence and memory. The pilot rows were renumbered to follow it (V0.9.33 to V0.9.45, after V0.9.32); their content is unchanged.

**Entry:** Required 0.5–0.8 outcomes are implemented; conditional deferrals and supported integrations/platforms are explicit. This line freezes features and closes observed failures.

**Exit:** Named pilots and exact-candidate release evidence satisfy the non-waivable access, data integrity, accessibility and recoverability gates; the maintainer can approve a concrete 1.0 artifact set.

**Scope control:** local OCR (0.6.22), a second tracker (0.8.7) and a second chat adapter (0.8.10) require a pilot owner before implementation. Jira/Slack are the default first choices; pilot evidence may select Linear/Teams instead before work starts. Record a deferral and narrow the supported feature list when a conditional item is not justified. Access boundaries, trustworthy evidence, recovery and publication isolation are mandatory. Full details and pilot thresholds are in the [readiness report](analysis/2026-10-29-team-readiness.md).
