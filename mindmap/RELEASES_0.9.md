# RepoMemo releases: 0.9 → 0.10 (CAIRN)

> **Current:** `V0.9.56` (2026-11-24)

> **Theme:** CAIRN, an agent over the team's governed evidence · **Baseline:** V0.8.67 · **Related:** [Roadmap](ROADMAP.md#the-09x-line-cairn-agent) · [CAIRN agent review](analysis/2026-11-22-cairn-agent-review.md) · [CAIRN harness plan](plans/2026-11-22-0.9-cairn-harness.md) · [ADR 0006](../docs/decisions/0006-cairn-is-a-bounded-tool-loop-over-governed-evidence.md)

**Status:** V0.9.0 to V0.9.32 were built on 2026-11-21 and are not yet validated. V0.9.33 to V0.9.70 were proposed on 2026-11-22; no such row is shipped or a release commitment. One intended commit per row, named `Update V0.N.P`, with a short body describing the change. Split oversized rows before implementation and renumber only unshipped rows. Update the changelog, user/API guides, mindmaps, archive compatibility and focused checks with the implementation, not in this planning change.

**The line changed purpose on 2026-11-22.** It was first the pilot line. It is now the CAIRN line, and the pilot rows that followed V0.9.32 (formerly V0.9.33 to V0.9.45) moved unchanged to the [0.10 line](RELEASES_0.10.md) as V0.10.0 to V0.10.12. Why: [ADR 0006](../docs/decisions/0006-cairn-is-a-bounded-tool-loop-over-governed-evidence.md).

**Tracks:** AN. CAIRN agent (V0.9.0 to V0.9.32: identity, voice, evidence, proposals, file, memory and note jobs; V0.9.15 to V0.9.24 are interface commits of the same track) · AO. Harness foundations (V0.9.33 to V0.9.38: provider messages, tool calls, an OpenAI-compatible provider, the tool registry, evidence tools) · AP. The bounded loop (V0.9.39 to V0.9.47: runs and traces, the loop, the citation ledger, untrusted content, live runs, changesets, trust signals, evaluation, the default) · AQ. Memory (V0.9.48 to V0.9.56: compaction, workspace instructions, team memory first, personal memory, past chats, corrections, playbooks, upkeep) · AR. Teams (V0.9.57 to V0.9.61: shared chats, tasks, chats across workspaces under each workspace's provider boundary) · AS. Bounded autonomy (V0.9.62 to V0.9.65: background runs, routines, event routines, review assistant) · AT. Other agents (V0.9.66 to V0.9.67: MCP endpoint, CAIRN inbox) · AU. Closing (V0.9.68 to V0.9.70).

**Entry:** the V0.9.0 to V0.9.32 jobs and the confirmation model exist. V0.9.34 to V0.9.38 change no behaviour a person sees.

**Exit:** in Agent mode CAIRN chains read tools, proposes changes that people confirm, cites only what it read, remembers in governed layers and works across workspaces without crossing a workspace's AI boundary; each model the guides name has a passing live evaluation; the CAIRN security review has no open high or medium finding; every row is ✅ or narrowed in the guides.

**Scope control:** CAIRN gets no outside MCP tools, shell, web or outbound messages in this line, routines never apply changes, and nothing CAIRN writes by itself steers anyone else's runs. The [plan](plans/2026-11-22-0.9-cairn-harness.md#excluded-on-purpose) lists what would reopen each exclusion.

**Type:** ✨ Feature · 🔧 Enhancement · 🐞 Fix · 🔒 Security · 📘 Update (docs, process, evidence, release).
**Status:** ✅ shipped (with date) · 🧪 built, not validated (committed with static checks only; the live evidence, walkthrough or run its row asks for is still owed) · 🔄 in progress · 🔜 planned. Every row starts planned; a written plan is not an acceptance-test pass.

## Verification and handoff

Before opening the 0.10 line, record the CAIRN walkthrough with a real provider, a live evaluation report for every model the guides name, the injection and cross-workspace negative cases, and the deletion and anonymization of traces, personal memory and chat search. Tests must demonstrate the user outcome, including failure and recovery. Follow the repository's execution rules; unrun checks remain explicitly unrun and the maintainer supplies live evidence.

Any new storage field, enum or entity must include its archive compatibility and migration handling in its own implementation. CAIRN's personal data (chats, traces, personal memory, chat search, shares, routines, inbox) is not part of workspace archives and is removed by account anonymization; memory cards, notes, playbooks and `CAIRN.md` are ordinary workspace content and travel with archives.

When a row ships, update this index and the matching roadmap row together; put the actual behavior and limitations in the changelog. The version range is an ordered plan, not a calendar forecast.
