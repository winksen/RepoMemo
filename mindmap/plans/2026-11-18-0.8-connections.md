# Plan for the 0.8 line: connected teams and community knowledge

Written 2026-11-18 for V0.8.0. Baseline: V0.7.20. Scope is the 0.8.x rows in the [roadmap](../ROADMAP.md#the-08x-line-connected-teams-and-community-knowledge) and the [release index](../RELEASES_0.8.md). The connector today is described in [technical/connectors.md](../technical/connectors.md).

## The decision this line rests on

A connector copies a source into **one workspace**, and everyone who can read that workspace can read the copy. That is a **deliberate shared-source import**: an admin decides that what the source holds may be seen by the whole workspace. RepoMemo does **not** mirror the per-user permissions of a source (a private Jira project, a Slack channel, a restricted Confluence page). A source that needs that is refused at connection time, never imported with the restriction dropped.

| Case | Supported | Why |
|---|---|---|
| A whole project, team or space whose readers are all (or a superset of) the workspace's members | ✅ Shared-source import | One audience, checked once, approved by an admin |
| A source with item-level restrictions (some issues hidden from some users) | ❌ Refused | The copy would show them to people the source hides them from |
| A source readable only by the token's owner | ❌ Refused unless an admin states the sharing is intended | The token is one person; the workspace is many |
| Mirroring each reader's own source permissions | ❌ Not offered | Needs a live permission check per read and per reader; not claimed in this line |
| A public source | ✅ | Nothing to restrict; still a copy in one workspace |

## The conformance contract

Every connector (GitHub and GitLab today, Jira in 0.8.5, Linear in 0.8.7) is described by the same eight facts. A connector that cannot state one is not added. Each fact has a fixture, named below, that an adapter must pass.

| Fact | Rule | Fixture |
|---|---|---|
| **Ownership** | The source stays the authority. Nothing is written to it. Remote state (status, assignee) is shown as the source's; a local follow-up is a separate record (0.8.8) | `own-readonly`: a sync makes no write call; a local edit never changes the item |
| **Audience** | One workspace, one audience, approved by an admin before the first import (0.8.1). The connection names the partition (project, team, space) it copies | `aud-uniform`: a partition with item restrictions is refused with the reason; `aud-secret`: a preview never holds a token or a secret |
| **Stable identity** | Each item has a remote id that never changes and is the key of the copy: the same id twice is one record | `id-repeat`: a page repeated, a retry and a restart create nothing twice |
| **Cursor** | A sync reads items changed since a stored cursor, oldest first, and stores the cursor only after the page is committed, so an interruption resumes and loses nothing | `cur-resume`: a sync stopped after page 2 resumes at page 3 with no gap and no duplicate |
| **Freshness** | The copy says when it was last read and whether the sync was complete, partial, stale or paused (0.8.3). A copy is never presented as current when the sync failed | `fresh-stale`: a source silent beyond its window reads stale, not complete |
| **Deletion** | A removed item is marked removed and leaves retrieval; a failure to read is not a deletion. The two are told apart by the source's own answer (`404` or a removed flag), never by absence from one page | `del-vs-fail`: a `5xx` page deletes nothing; a `404` item is removed; a page that omits an item removes nothing |
| **Rate limits** | A `429` or an exhausted quota pauses the connector with a stated end; a wait of 30 s or less is slept, a longer one pauses; a refused token pauses with no end until replaced (exists since V0.2.31) | `rate-pause`: the pause reason, its end and the resume are recorded |
| **Permission loss** | When access to the partition is revoked or sharing can no longer be established, the copied evidence is quarantined (0.8.2): out of retrieval, previews, exports and publication, kept until an admin decides | `perm-lost`: a `403` on the partition quarantines the items; a transient `403` with quota left is not treated as loss without a second check |

The words used for the outcome of a sync are fixed: **complete** (every partition page read, no error), **partial** (some pages or items skipped, listed), **stale** (no success within the window), **paused** (rate limit, refused token or an operator), **quarantined** (access lost).

A cell that reads *refused* means the partition cannot be connected until the restriction is gone; it is never imported with the restriction ignored.

## Rules for the whole line

1. **No credential travels with data.** Tokens and webhook secrets are sealed in the credential store and appear in no preview, export, archive, log or event.
2. **Nothing outside is called without an operator's allowance.** Hosts come from the allow-list (`REPOMEMO_GIT_ALLOWED_HOSTS`, extended to each new adapter); outbound webhooks and chat destinations are approved one by one and each has an off switch that stops queued content.
3. **Outbound content is a link, not text.** A chat or webhook message carries an identifier and an authenticated link; titles and excerpts of restricted content never leave the server.
4. **Publication is a copy, never a view.** A public snapshot holds only what a person reviewed and approved as public; revoking a source or withdrawing the snapshot stops serving it without touching the private original.
5. **Archives carry facts, not authority.** An import keeps attribution and provenance, reconnects no credential, sends no webhook and publishes nothing until an admin authorizes it again (0.8.19).
6. **Conditional adapters need an owner.** Linear (0.8.7) and Teams (0.8.10) are built only when a pilot owner is named; otherwise the row records a deferral and the guides claim nothing.

## The exit journey the closing release walks

1. Connect one tracker project to a workspace: the preview names the partition, the copied fields and the audience; an admin approves uniform sharing.
2. Read the first import; stop it half way and resume; see health report *partial*, then *complete*.
3. Edit and delete an item in the tracker; resync; see the change and the removal, with no duplicate.
4. Revoke the token's access; see the evidence quarantined and gone from search, exports and publication.
5. Link a mirrored issue to a local task; edit the task; see that the issue's remote state did not change.
6. Receive a review digest in chat as links only; open one as an authorized reader and fail as a stranger; disconnect and receive nothing.
7. Migrate a Markdown directory and a Confluence export with links and attachments intact; retry and create nothing twice.
8. Publish a reviewed snapshot; read it anonymously and search it; withdraw it and see it stop being served.
9. Move the workspace by archive; see attribution kept and no credential, webhook or publication active until reauthorized.
